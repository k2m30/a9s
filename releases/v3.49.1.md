# v3.49.1 — Patch

- `-c events` / `:events` resolution is no longer registration-order luck:
  the alias was registered on both CloudTrail events and EventBridge rules,
  with CloudTrail winning by chance. The duplicate is removed — `events`
  belongs to CloudTrail events (the documented behavior); EventBridge rules
  answer to `eb-rule` and `eventbridge`.
- New catalog gate: every command name (alias or short name) must map to
  exactly one resource type, so an ambiguous alias can never ship again.
