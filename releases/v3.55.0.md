# v3.55.0 — Honest related-count truncation + Cost Explorer test robustness

## Related panels tell the truth about truncated counts

The related-resource panel renders `N+` when a count is a lower bound — the
target cache was only partially scanned, so more may exist beyond what was
counted. Two problems undermined that signal:

- The per-resource documentation's **"Truncated?"** column was generated
  from `NeedsTargetCache`, a prefetch flag that says nothing about whether a
  count can actually be truncated. The column carried stale, wrong values
  across every `docs/resources/*.md`. It is now generated from a new
  `domain.RelatedDef.Truncated` flag — the single source of truth for
  truncatability — set from each checker's real behavior.
- 13 reverse-scan and count checkers returned an exact count where the real
  answer is a truncated lower bound, so the panel showed, for example, `3`
  when it should have shown `3+`. These now propagate the truncation flag;
  identity-resolvers that cannot resolve against a truncated parent show `?`
  (unknown) rather than a false `0`.

## "Approximate" retired in favor of "Truncated"

The renderer vocabulary is unified on "Truncated". The exported
`resource.FormatApproximate` / `CellKindApproximate` become
`FormatTruncated` / `CellKindTruncated` — a **breaking change** for external
importers of the now-public `core/resource` package. AWS's own wire fields
(`ApproximateNumberOfMessages`, ...) and the SQS domain keys keep their
names; only the a9s truncation concept is renamed.

## Cost Explorer resource-drill tests robust to the calendar

Six resource-drill tests drilled into the first day of the current month and
pressed Enter on that cell. AWS only allows resource-level cost detail for
the last 14 days, and a9s correctly refuses older cells — so from the 15th
of each month onward those tests hit an un-openable cell and failed. The
tests now drill into the current day (always inside the window) and share
one clock across their headless and TUI lanes. The 14-day guard is correct
and untouched. (A related UX wart — the drill cursor parking on the oldest,
often un-openable column — is tracked separately.)

## Hardening

A CodeQL path-injection finding on the cache path is closed with an
`IsLocal` containment guard, and a controller close-discipline gate fixes 8
leaked controllers that only surfaced under shuffled test ordering.
