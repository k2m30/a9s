# v3.58.1 — every screen answers from what AWS actually returns

A patch on v3.58.0 from two external review passes, triaged against
`main` and fixed in seven tasks.

## Fixed

Internet exposure. An EC2 instance is judged per network interface,
against that interface's own security groups, subnet and address family:
a rule open to `::/0` no longer flags an IPv4-only instance, an
IPv6-only instance behind an internet gateway is flagged, and an instance
behind a NAT gateway is not. A security group or route table that was not
read makes the instance not inspected instead of clean, and so does a
default route through a Gateway Load Balancer or Network Firewall
endpoint, which the subnet's own route table cannot judge. A bucket whose own
`RestrictPublicBuckets` is on is not public; a CloudFront distribution
serving any path over plain HTTP is reported; a trail whose bucket is
public through an ACL is reported. Lambda posture and CloudFront
origin-bucket checks run on live sessions again.

Values read as AWS sends them. VPC endpoint states are compared in the
lower case AWS uses, so failed and pending endpoints show again. Lambda
state comes from `GetFunction`, which is the only call that returns it,
and the end-of-life check follows AWS's past and scheduled runtime
deprecation dates. ECR critical and high counts come from
`DescribeImageScanFindings`, since current Basic Scanning no longer puts
them on `DescribeImages`.

Complete answers. ACM lists ACME-issued certificates; a regional web ACL
protecting only an API Gateway stage, AppSync API, Cognito user pool or
similar is no longer called unassociated; OpenSearch describes more than
five domains; a CloudFront web ACL counts past its first 100
distributions.

Databases. Every DB cluster and DB instance status in AWS's tables has
its own phrase and severity, failed states count as broken, and a stopped
cluster reads like a stopped instance. DB Clusters no longer lists
Neptune, and Aurora clusters are read from RDS so their posture checks
run. A global database secondary or replica is not "no writer"; a global
primary without one still is.

Pivots and logs. EKS counts self-managed, Karpenter and Auto Mode nodes
by their cluster tags. Athena links the log group its logging
configuration names. The ECS service log view and the Lambda invocation
list open on the newest events; the service view reads only the
service's own streams, in the `awslogs-region` it names. The log-stream
and build log views page back through a long stream instead of presenting
its newest page as the whole log.

Lambda invocations. JSON-format functions list their invocations; a
failed invocation reads `ERROR` with its error type; a SnapStart restore
counts as a cold start; a function on a shared custom log group lists
only its own; an invocation's log shows every line of its stream,
including output without the request ID.

The snapshot collector no longer writes secret values to
`snapshot.json`. A file written by an earlier version still holds them:
delete it or collect again.
