# v3.52.0 — Launch Templates, and details that tell the whole truth

## New resource type: EC2 Launch Templates (`lt`, aliases `launch-template`, `launchtemplate`, `launch-templates`, `lts`)

- Browse launch templates — the 69th resource type. One extra call per
  template reads the `$Default` version (what ASGs, node groups and
  instances actually resolve at launch — `$Latest` is staging), funding
  every pivot and every warning.
- Two security warnings a fleet owner actually chases: `IMDSv1 allowed`
  (HttpTokens not `required` — and unset DEFAULTS to optional, the trap;
  templates with the metadata endpoint explicitly disabled are exempt) and
  `EBS encryption disabled` (explicit `Encrypted=false` only — nil is
  unknown in default-encryption accounts, never flagged).
- A `~` background check marks templates whose default version references
  a deprecated AMI — cross-referenced against the already-loaded AMI list
  with zero extra API calls.
- The related panel answers the blast-radius question: which Auto Scaling
  Groups (plain, mixed-instances policy, per-Overrides), which EKS node
  groups, and which running instances (via the `aws:ec2launchtemplate:id`
  auto-tag) launch from this template — plus the AMI, KMS key, security
  groups and pinned subnets of the template itself. Truncated sibling
  lists answer `?`, never a fake zero.
- A template whose `$Default` version is denied keeps every listed field
  plus `details denied` — the rich degradation contract.

## Details that tell the whole truth

- Transfer agreement details now show the RESOLVED AS2 IDs for both
  trading partners (previously the bare profile ids), and certificate
  findings — expired AND expiring — all reach the Attention section
  (previously at most one survived the fold). Detail enrichment now
  carries every finding for every type.
- OpenSearch domains listed by a role denied `es:DescribeDomains` degrade
  to `details denied` rows instead of vanishing with a hard error.
- Humanized columns stay humanized on warm-cache rows — no more raw
  `AMAZON_ISSUED` where the live render says `Amazon Issued`.
- Zooming out on a resource-level Cost Explorer drill stops at the 14-day
  retention boundary instead of firing a multi-month resource query that
  replaced the grid with a validation error.

## Process

- `make ready-to-release` is now additive on top of `make ready-to-push` —
  integration plus the live read-only smokes, without re-running the whole
  push gate.
