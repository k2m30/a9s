# v3.58.0 — a cell says what AWS reported

v3.57.0 gave every row a verdict. This release is about whether that
verdict is *earned*: 136 fixes across the catalogue, almost all of them
one place where a9s answered from an assumption instead of from what
AWS returned.

## Calls that under-asked

A verdict is only as good as the request behind it. ACM's certificate
list answers with RSA-1024 and RSA-2048 alone unless asked otherwise,
so every RSA-3072, RSA-4096 and EC certificate was missing from the
list and from each pivot that resolves one. `DescribeImages` omits
disabled AMIs, and `DescribeNetworkInterfaces` omits AWS-managed
interfaces, unless the flag is set. ECS services and tasks came back
without their tags on several paths. CodeBuild refuses a sort order on
a project with more than a hundred builds — precisely the busiest
projects, which is why their latest-build status was blank.

## Fields read where AWS actually puts them

A DynamoDB table with no billing summary is provisioned; the column was
blank. An ElastiCache group names its effective encryption state
separately from the at-rest flag, so encrypted caches were told to turn
encryption on, and a cache using RBAC — which cannot also carry an AUTH
token — was reported as having no authentication at all. An Auto
Scaling group's health-check type is a comma-separated list, so ELB
health is a membership test, not an equality one. The MSK Version
column rendered `CurrentVersion`, the opaque revision token AWS carries
for update calls, where an operator reads the Kafka version.

## Verdicts that waited for a condition to apply

A group created this week has no members by construction, and a role
created today has no recorded use: neither is an orphan or dormant
until it is old enough to be. A completed scheduled EC2 event is not a
pending one. A Windows task definition is not judged by a Linux
root-filesystem rule. A distribution served on its own cloudfront.net
name carried a TLS warning that could not be acted on — AWS pins that
setting to TLSv1 on the default certificate whatever the config says.
A KMS key on its way out is no longer asked for its key policy.

## Numbers and phrases

An alarm threshold renders at the precision CloudWatch reports it: an
error-rate alarm at 0.005 showed `0.00`, which reads as firing on
anything above nothing. A Transfer certificate with hours left on it
expires in one day, not zero. A dotted AWS enum reads as words —
`Gateway.NotAttached` was rendering as `gateway. not attached`. A
CloudTrail event acting on several subjects names the first and counts
the rest instead of being cut mid-identifier, and the ORIGIN column is
blank rather than showing a `?` that reads like an origin of its own.

## Related-panel honesty

A subnet with no explicit route-table association falls back to its
VPC's main table — a fallback that asserts "no table names this
subnet", which an unread page can falsify; it now stays silent when the
table list is incomplete. An API Gateway log-group pivot counted any
group whose name merely started with the prefix, and an EventBridge
rule scoped to one repository counted for another whose ARN was a
prefix of it.

## Demo fidelity

The demo is the fixture every gate and every screenshot reads, so a
fixture that asserts a shape AWS would not produce is a lie the whole
suite repeats. Twenty-seven IAM policies advertised attachment counts
no principal backed. The pipeline declared two actions AWS would reject
outright. Two wave-2 witnesses sat past the enrichment cap, so a backup
verdict appeared only for the one row you happened to open. The EC2
fake ignored `DescribeNetworkInterfaces` filters, so drilling any
resource's interfaces listed every interface in the account.

## Gates

The Playwright browser suite now runs in `make ready-to-push`. It was
CI-only, so a demo-fixture change could break the rendered web lane
with every local gate green — which is exactly what happened on the
previous release's push.
