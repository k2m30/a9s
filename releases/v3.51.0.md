# v3.51.0 — Transfer Family, and profile switching stops paying the full toll

## New resource type: Transfer Family (`transfer`, aliases `sftp`, `as2`, `ftps`)

- Browse SFTP/AS2/FTPS servers — the 68th resource type. Status phrases per
  lifecycle state (`offline: not accepting transfers`, `start failed`,
  `stopping`, …) plus the two warnings a B2B operator actually chases: a
  legacy security policy still allowing weak ciphers / old TLS, and a server
  writing no activity logs at all.
- The related panel jumps to the ACM identity certificate, the Elastic IPs
  partners allowlist (internet-facing endpoints), the Lambda authorizer, log
  groups, the logging role, subnets, the VPC and its endpoint, and the
  CloudTrail audit trail. Seven detail fields navigate directly — including
  the subnet list, the endpoint's Elastic IPs, and the authorizer function.
- **Agreements child view**: press `e` on a server to list its AS2
  agreements. An inactive agreement warns `inactive: partner traffic
  rejected`; opening one resolves both trading-partner profiles and flags
  expired (or soon-expiring) certificates.
- A server whose describe call is denied keeps everything the list already
  said about it — domain, endpoint type, state — plus `details denied`. The
  honest-degradation contract from v3.50.0, now in its rich form.
- Demo mode ships 12 servers covering every state, a fully connected AS2
  showroom gateway, and a listed-but-denied witness.

## Profile switching stops paying the full toll

The availability sweep now runs **once per session per profile–region
pair**. Switching to another profile and back no longer re-probes all 68
types and re-runs every background check — the revisited pair renders
instantly from what this session already learned. An interrupted sweep
picks up where it left off on revisit, and `Ctrl+R` on the main menu still
forces a full re-sweep when you want one.

## Fixed

- `y` (YAML), `J` (JSON) and `t` (CloudTrail) were dead while the related
  column held the cursor — the focused panel swallowed every key as filter
  input. They now act on the resource under view regardless of focus, and
  `h` returns the cursor to the detail body.
