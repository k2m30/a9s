# v3.54.0 — Importable core + dual licensing

The platform-agnostic core of a9s — the resource catalog, AWS fetchers,
runtime, headless controller, session state, and web adapter (16 packages)
— moved from `internal/*` to `core/*` and is now importable by external Go
modules as `github.com/k2m30/a9s/v3/core/...`. The TUI adapter stays at
`internal/tui`. This is a pure move plus import rewrite: zero behavior
change, a9s remains read-only toward AWS, and the core still compiles with
no Bubble Tea / Lipgloss dependencies (an external consumer module pulls
zero renderer packages).

Licensing is now explicit and dual:

- **LICENSE** carries the full GPL-3.0 text (previously a pointer file),
  with the copyright line set to the copyright holder.
- **COMMERCIAL-LICENSE.md**: the `core/` packages are additionally offered
  under a separate commercial license by the copyright holder, for building
  derived applications without copyleft obligations. The TUI is GPL-only.
- **CONTRIBUTING.md** now requires a CLA (Apache ICLA based) for any
  contribution touching `core/`, which is what keeps the dual-licensing
  arrangement sound long-term.
- SPDX headers on every Go file: `core/**` is
  `GPL-3.0-or-later OR LicenseRef-Commercial`, `internal/tui/**` is
  `GPL-3.0-or-later`.
- Dependency audit (`go-licenses report ./core/...`): every third-party
  dependency is Apache-2.0, BSD-3-Clause, or MIT — nothing copyleft.

Static-audit tests that walked `internal/` now walk both `core/` and
`internal/`, so the conformance gates (row-store shapes, mutation seams,
sentinel bans, cache chokepoint) kept their full coverage across the split.
