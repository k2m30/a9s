# v3.50.0 — Managed Airflow, and lists that never lie

## New resource type: Managed Airflow (`mwaa`, alias `airflow`)

- Browse MWAA environments — the 67th resource type. Status phrases per
  lifecycle state (`creating snapshot`, `pending: awaiting VPC endpoints`,
  `rolling back: update failed`, …), plus two warnings operators actually
  chase: a last update that silently failed while the environment keeps
  serving the old config, and a webserver reachable from the internet.
- The related panel jumps to the five per-component CloudWatch log groups,
  the execution role, the DAG source bucket, KMS key, security groups,
  subnets, `AWS/MWAA` alarms, and the CloudTrail audit trail.
- Demo mode ships 17 environments covering every state, a fully connected
  showroom environment, and a listed-but-denied witness.

## Lists that never lie

This release makes honest degradation a fleet-wide contract, driven by three
live findings on real accounts:

- **A denied describe never hides a resource.** When the list API names a
  resource but the per-item describe is denied (IAM) or returns nothing, the
  row stays — name visible, `details denied` in the Status column, the cause
  in the `!` error log. Adopted by MWAA, EKS clusters, node groups, DynamoDB
  tables, and OpenSearch domains through one shared implementation.
- **Partial success renders, totals fail loudly.** Rows arriving alongside a
  per-item composite error render with their findings; the error goes to the
  `!` log instead of a blocking banner. Related-panel caches keep partial
  rows instead of answering `?`.
- **Region gaps say so in plain language.** A service whose endpoint does not
  exist in the selected region logs `service not available in region X`
  instead of DNS transport jargon.

## Fixed

- MWAA list pagination uses the API's `MaxResults` cap of 25 (the shared
  default of 50 was rejected with a `ValidationException`).
- The live smoke now reads the `!` error log after its full catalog walk —
  a type whose fetch errors can no longer slip through the sweep unseen.
