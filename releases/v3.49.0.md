# v3.49.0 — The Cleanup Release

Net **−37,700 lines** across 434 files, **−4 dependencies**, **5 real bugs
fixed** — with behavior pinned before every deletion.

## Bugs found and fixed by the cleanup itself

The legacy pre-controller view layer was dead code, but its orphaned tests
were the only thing pinning several documented behaviors. Porting those pins
onto the live paths before deleting anything surfaced real regressions:

- **Four dead keys on text screens.** `y`/`J` (YAML↔JSON toggle), `t`
  (CloudTrail events), and `d` (open detail) did nothing on live YAML/JSON
  views — the controller migration never wired them into the text-screen key
  handler. All four now work and are pinned on the real key path.
- **YAML coloring corrupted colon-bearing keys.** A key like
  `aws:autoscaling:groupName` was split at the first colon, so the displayed
  YAML no longer parsed. The colorizer now finds the real key/value separator
  (quote- and escape-aware); stripping colors always yields the original text.

## What was removed

- The legacy view-model layer superseded by the 020 controller/ViewState
  architecture: dead self-render paths, constructors, and accessor families
  across every view — plus ~28,000 lines of tests that existed only to drive
  that dead code. Every unique pin they held was first re-created on the live
  controller seams (44+ new tests).
- Dead design-mockup binaries, a never-wired Lambda code-download module,
  110+ test-only pagination wrappers, 50+ byte-identical related-resource
  wrappers, 100+ copy-pasted client assertions, ~44 hand-rolled pagination
  loops in the snapshot tool, and a duplicate README generator.
- `testify` (+2 transitive) and `ini.v1` dependencies.

## Architecture

- **One truth source for column resolution.** The identity/marker-column
  cascade existed as three hand-synchronized copies (one carried a comment
  begging them to stay identical). All lanes now delegate to a single shared
  `resource.ResolveListColumnCascade`.
- Every deletion in this release required positive evidence: zero callers
  proven per symbol, or a named surviving test equivalent verified before
  the legacy test died. Where verification found live consumers, the audit
  was corrected instead — nine original audit claims were struck this way.

## Process notes

- Two independent audit passes (the second falsified two conclusions of the
  first and found four wrappers plus one orphaned module it had missed).
- Homebrew publishing fixed for good (#455): GoReleaser's deprecated `brews:`
  is gone; releases render and push `Formula/a9s.rb` themselves from the
  release checksums, with the generation path validated before publishing.
  `brew install k2m30/a9s/a9s` installs a formula — no cask quarantine.
